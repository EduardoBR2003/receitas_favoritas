# Receitas Favoritas

Atividade 4 – Navegação entre telas.

Aplicativo Flutter de receitas com navegação por abas (Doces, Salgadas e Bebidas) na parte inferior, tela de detalhes para cada receita e menu lateral (Drawer) com as telas de Configurações e Sobre.

## Como executar

```bash
flutter pub get
flutter run
```
